# Craftive Studio — One-Page Landing (v2)

React + Vite + Tailwind + Framer Motion

## Install
```bash
npm install
```

## Run locally
```bash
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Edit branding
Open `src/config.js`:
- brand
- phoneDisplay
- whatsappNumber (digits only)
- email
- calendly (optional)
- projects / logos / testimonials

## Deploy
- Vercel: build `npm run build`, output `dist`
- Netlify: build `npm run build`, publish `dist`
